# Safety Net

AI-assisted safety platform that analyzes real-time location streams to detect abnormal mobility patterns and trigger emergency alerts.

Features

• Real-time location tracking  
• ML anomaly detection  
• FastAPI backend  
• REST APIs  
• Data analytics pipelines  

Tech Stack

Python
FastAPI
Scikit-learn
Pandas
SQLite
Google Maps API

Run Locally

pip install -r requirements.txt

uvicorn app.main:app --reload

Deployment

Docker + Render
